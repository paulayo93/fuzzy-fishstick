# Ovwspelo Limited

Experimental marketing site for **Ovwspelo Limited** — oil and gas engineering.

**Tagline:** Engineering Solutions. Delivering Excellence.

Built with Vite, React, TypeScript, and Tailwind CSS. Pages: Home, About, Contact, Blog.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
